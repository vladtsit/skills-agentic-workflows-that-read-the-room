## Agentic workflows worth trying

Source: [Awesome Copilot workflows](https://awesome-copilot.github.com/workflows/) (published in [github/awesome-copilot](https://github.com/github/awesome-copilot/tree/main/workflows)). Ready-made agentic workflow samples you can copy and adapt:

- **Daily issues report** (`daily-issues-report`): a recurring summary of repository issue activity.
- **OSPO reports** (`ospo-contributors-report`, `ospo-org-health`, `ospo-stale-repos`, `ospo-release-compliance-checker`): open source program office checks for contributors, org health, stale repositories, and release compliance.
- **Relevance check and summary** (`relevance-check`, `relevance-summary`): triage helpers that judge and summarize how relevant incoming items are.
- **Weekly comment sync** (`weekly-comment-sync`): a scheduled workflow that keeps comments in sync.

Tip: start with one read-only report workflow, review its output, then expand.
